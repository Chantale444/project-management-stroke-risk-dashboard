# Assignment 2 — Project Charter

The project charter translated the initial project idea into a structured project plan.

The team worked with an Agile development approach and developed the project plan together.

The project charter included:

- Project objectives and scope
- Work Breakdown Structure (WBS)
- Scheduling
- Gantt diagram
- Risk assessment
- Cost estimation
- Strategic alignment
- Project progress

The project charter was presented and discussed during a seminar, where the team also received feedback from peers.
