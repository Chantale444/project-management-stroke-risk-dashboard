# Assignment 3 — Final Project Report

The final report documents the development of the Stroke Risk Prediction Dashboard and reflects on the project from three perspectives:

- Project Management
- Data Science
- Design Process and User Evaluation

The report describes the team's Agile-inspired development approach, group development, leadership and collaboration, as well as the data-processing pipeline, descriptive and diagnostic analytics, machine-learning classification, SHAP-based explainability, dashboard prototyping and usability evaluation.

The project was developed collaboratively by the group, with different members contributing to different activities.
