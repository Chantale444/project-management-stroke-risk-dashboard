# Dashboard Code

This folder contains the Python code used to implement the Stroke Risk Prediction Dashboard in Streamlit.

The dashboard integrates the data science pipeline with an interactive user interface and includes:

- Dashboard navigation
- Descriptive analytics
- Diagnostic analytics
- Risk prediction
- Preventive analytics and model explainability
- About/project information
- User-interface safety and validation

The dashboard was developed collaboratively by the project group.
